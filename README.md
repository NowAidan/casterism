# How to Run

* This project was developed on and requires **Python 3.13.5** and **pygame-ce 2.5.8** or later installed. A guide to install Pygame-ce can be found below.
   * *This project might still be able to be ran on the original pygame, however you may encounter some bugs or other issues*
* Download the project as a ZIP file from the "Code" dropdown on the main repo page.
* Extract the source from the ZIP file and open the program in your preferred Python interpreter.
* Run the program by simply executing it from the 'main.py' file.

# pygame-ce Installation Guide (VS Code)
pygame-ce is a fork of the original pygame, effectively replacing the original library which has now become outdated and largely unactive.
**Blurb from the pygame-ce GitHub:**
>It [pygame-ce] is a fork of the upstream pygame project by its former core developers, and was created after impossible challenges prevented them from continuing development upstream. The new distribution aims to offer more frequent releases, continuous bugfixes and enhancements, and a more democratic governance model.

* Open Visual Studio Code
* Terminal > New Terminal
* Within the terminal enter the following installation command:
`pip install pygame-ce`
